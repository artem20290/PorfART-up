# Кабинет администратора — доска поручений

Управленческий контур поверх канбана: не только просрочки, а весь админ-функционал.

## Сценарии

| Запрос | Что делает агент |
|--------|------------------|
| Сводка доски | KPI статусов, доля просрочек vs SLA |
| Просрочки | Реестр + эскалация владельцам |
| Высокий приоритет | High-карточки и просроченный high |
| Исполнитель | Нагрузка (напр. Петров) |
| Предприятие | Срез Альфа / Бета / УК |
| К совещанию | Повестка для дирекции |

## Роли

- **Исполнитель** — канбан и голосовой помощник на доске  
- **Администратор** — этот кабинет + ⚙ настройки агента (LLM, RAG, режим)

## Архитектура

Plan-and-Execute / ReAct → RAG → tools → ответ.  
n8n: `n8n/overdue-report.workflow.json` (можно расширить на другие сценарии).
